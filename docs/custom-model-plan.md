# 自制 Live2D 模型方案（设计稿，未执行）

> 目标：摆脱 hiyori 的授权限制（禁改设计 / AI 用途待确认），为 Ayan 制造一个
> **完全自有、可商用、完全适配桌宠** 的 Live2D 模型。
> 调研时间：2026-10-15。本文件只做方案，不含任何已执行动作。

## 0. 背景与动机

- hiyori 官方样本数据对个人可商用，但两条绳索：**禁改角色设计** + **AI 聊天用途
  可能被官方归类为"可扩展性 APP"（需逐作品签约，邮件待发）**。
- 上 Steam 商业发行后这两条都会被放大。自制模型一次性解决：设计权、改动权、
  发行权全归项目（只剩 Cubism SDK 本身的许可，反而更宽松）。
- 已有架构红利：`e0fbc28` profiles 档案化后，**加模型 = 建档案 + 注册一行**，
  runtime 侧适配成本已压到最低。

## 1. Live2D 模型的四道工序（与能力对照）

| 工序 | 内容 | 纯人工基准 | 我方能力（2026 工具链） |
|---|---|---|---|
| ① 角色设计 + 立绘 | 人设、三视图、定稿立绘 | 画师 3~7 天 | ✅ ImageGen 迭代概念图可行 |
| ② 分层 PSD | 眼白/瞳孔/睫毛分层、张嘴差分、前后发分离、**被遮挡区域补全**，几十层 | 画师 1~2 周 | ⚠️ 最弱环。Bunraku（2026 研究，单图→分层→绑定）证明可行但未生产级 |
| ③ 绑定 rigging | 网格、变形器、参数、物理 | 绑定师 1~4 周 | ✅ `psd2live`（开源）：分层 PSD → 自动 .moc3/.cmo3，可回官方编辑器精修 |
| ④ runtime 适配 | 档案、情绪 16 字段、摸头、走路 | — | ✅ 本行，估 4~5 工作日（详见 §4） |

## 2. 三条路线

### 路线 A：全自动（我 + AI 工具链，零人工外购）
- 流程：ImageGen 设计定稿 → AI 分层（Bunraku 式/prompt 拆层）→ psd2live 自动绑定 → 档案适配。
- 时间：**1~2 周 demo**。
- 判死刑的两点：
  1. AI 分层的遮挡补全质量不稳（眼皮后的瞳孔、发丝后的肩），绑定撕裂风险高；
  2. **自动绑定工具链全部是 VTuber 半身向，没有人给"腿"做优化** —— 桌宠刚需的
     全身漫步/走路循环做不出来。
- 结论：只配当 PoC，不配当交付路线。

### 路线 B：半自动（推荐）✅
- 流程：我出设计定稿 → **画师做分层 PSD（唯一外购人工，约 1~2 周）** →
  psd2live 自动绑定 → 我做绑定精修 + runtime 适配。
- 时间：**2~3 周日历时间**（画师与我并行度高）。
- 成本：画师分层 PSD 行情约 ¥2000~6000（按层数与差分复杂度）。
- 品质：接近商用——分层是人工的（质量可控），绑定自动化后人工精修兜底。

### 路线 C：传统全委托
- 画师 + 绑定师全外包：1~3 个月、数万元。放弃设计参与权，不推荐。

## 3. 设计规格（路线 B 的输入，也是给画师的委托书骨架）

**硬性需求（来自现有系统，缺一个 runtime 适配就多一天）：**

| 项 | 规格 | 为什么 |
|---|---|---|
| 形态 | **全身正立、真人比例（不要二头身 Q 版）**，含完整腿脚 | 漫步/回位/贴边全靠腿；sjmsltx 实测：Q 版脸太小不适合 Live2D 表情（见 open-source-reference.md 11.1-A3） |
| 基础差分 | 眼开/闭/半闭、口开/闭/半开、视线四方 | EMO_SPEED 错峰插值 + 口型 |
| 表情差分 | 眉（左右各 3 态以上）、脸红层 | 8 情绪 × 16 字段 |
| 张嘴结构 | 口腔内（上牙/下牙/舌头分件） | 口型正弦驱动不穿帮 |
| 头发 | 前发/后发分离，后发遮肩区域留余量 | 物理摆动 + 转头 |
| 被遮挡补全 | 眼皮后瞳孔、发后身体、四肢根部长度补全 | 所有变形的原料 |
| 分辨率 | 原画 ≥2048 高，纹理出厂即 1024（复用现有降采样流程） | 省内存的路已铺好 |
| 部件命名 | 按 psd2live 命名表（它的自动识别靠这个） | 自动绑定通过率 |

**设计自由度：**
- 风格与 hiyori 元气少女/ Miara 御姐错位（建议"第三种气质"，比如冷静系/治愈系），
  与未来双角色互补；
- 人设由我们定 → 名字/自称/人设全部自有一致（resolveName/resolvePersona 零妥协）。

## 4. runtime 适配（工序④，我独立完成，估 4~5 工作日）

| 阶段 | 内容 | 估时 |
|---|---|---|
| 挂载冒烟 | profiles/<new>.js 档案 + 注册 + 几何标定（inkW/headTop 实测） | 0.5 天 |
| 情绪 16 字段×8 | 数值全重调 + 错峰插值节奏重定（迭代试错型，不可压缩） | 1.5~2 天 |
| 摸头 A-B-C | PAT/PAT_DELTA + headTopY 复验 | 0.5 天 |
| 走路/拖拽 | make-motions.js 自制（自家模型无版权顾虑，随便剪随便做） | 0.5~1 天 |
| 收尾 | models.zip、config 模型键、托盘切换、两档窗口复验、verify 双模型化 | 1 天 |

## 5. 时间线（路线 B）

```
W1    设计迭代（ImageGen 概念 → 定稿）→ 下单画师分层 PSD
W2    画师制作（并行：我做绑定精修工具准备 / 预研 psd2live 输出结构）
W3    psd2live 绑定 + 精修 → runtime 适配 4~5 天 → 双模型回归
```

关键路径是画师；我的工时合计约 7~9 个工作日，其中 5 天在关键路径上。

  官方授权确认"，届时重估。
